# Bodega COCOA — Plataforma de reservas

Proyecto final de **Desarrollo Web 3** · Universidad San Francisco de Quito.

**Equipo:** Juanes Vargas y Ailyn León  
**Cliente:** Bodega COCOA, USFQ

Plataforma web adaptable a computadoras y móviles para que estudiantes y profesores autorizados de COCOA exploren el catálogo de equipos audiovisuales y espacios, soliciten varios artículos en una sola reserva y sigan su estado; y para que el personal de la bodega apruebe solicitudes, controle el inventario y registre entregas y devoluciones.

> *Less friction. More creation.*
